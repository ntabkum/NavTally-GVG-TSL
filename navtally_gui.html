Additional UMD destinations (TSL UDP)
Every TSL packet is also sent to these hosts, using the protocol, screen and interface chosen in the UDP destination panel above. Leave the port empty to use the main UDP port. The main destination plus up to 9 additional hosts = 10 receivers. Give a host a start address to send it only that display (count 1 = a single display, or set a count for a range); leave the start address empty to send it every display. Each host can also use its own network interface (pick a detected NIC or type a local IP); empty = the same interface as the main TSL output.
